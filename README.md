# gatehtml

Gate encode/decode helpers for html payloads in pipelines.

**Site:** https://theworker02.github.io/gatehtml/

## Install / run

```bash
git clone https://github.com/theworker02/gatehtml.git
cd gatehtml
node src/cli.js
node --test
```
